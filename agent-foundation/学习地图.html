Application Harness

应用级 Harness：你的框架的核心

它决定模型、工具、安全与预算如何组合；不需要你重新写 Agent Loop。

  • 按 YAML 装配 Agent。
  • 工具白名单、调用预算、有限重试。
  • 带审批的本地草稿、会话 Checkpoint。
graph = create_agent(
  model=model,
  tools=tools,
  middleware=policies,
  checkpointer=InMemorySaver(),
)

03 · 三条命令，理解整个框架

# 第一步：运行纯业务逻辑，不使用 LLM
python -m foundation.cli demo support_insights

# 第二步：自动测试业务正确性
python -m unittest discover -s tests -v

# 第三步：使用真实 Agent Loop（先安装依赖并启动 Ollama）
python -m foundation.cli run support_insights --trace --message "分析最近7天的投诉，找到前3个证据"

完整安装命令在 README.md 中。工程目录已经提供两个 Agent、一个可复制的模板以及更详细的中文课程。

04 · 这是教学工程，不是生产授权系统

当前只提供内存会话、CLI 人工审批、本地数据/草稿和最小行为 Eval。真正生产部署还要接认证权限、持久化状态、审计、幂等写操作、敏感信息保护和准确率回归测试。此项目的离线测试通过不等于真实 LLM 全链路已通过。
