# 开发与修改方法

用途：当前助手接到新Agent、已有Agent修改、共享能力扩展或失败续接任务时使用。本文拥有实际工作步骤和分类配方的内容要求；产品要达到什么见[产品需求](产品需求.md)，具体任务状态只在[当前工作](当前工作.md)或相应业务任务记录维护。

## 先定位任务与权威

1. 从[主索引](../../CODEX_START_HERE.md)定位相关要求、当前任务与已有决定，区分新建、修改、恢复和只解释。已确认内容直接继承。
2. 查看用户允许的实际材料、相关资产与代码消费者。用真实输入、操作、输出、例外和通过条件对齐任务；不把虚构示例当材料或成功。
3. 按产品地图判断所需组成及依赖：程序/单次模型/固定Workflow/动态Agent哪个必要，哪些复用、配置、业务新增或共享扩展。必要能力未接通时保留缺项，不缩掉需求。
4. 只对未决且影响取舍的问题使用已安装grilling；技术事实由助手调查。相应研究、可行性、架构与实施门槛使用已安装coding-workflow及research-and-architecture，不因有旧报告就跳过本次适用核实。

## 每类配方必须表达的合同

下列十项内容从原产品文档的配方要求迁入，本处唯一维护。它们约束方法内容，不要求每项单独创建文件。

1. **何时适用：** 从真实需求识别是否需要该能力，不需要时说明理由。
2. **先查什么：** 已有资产、框架、依赖的支持范围及来源、版本和证据。
3. **怎样选择：** 复用、配置、薄适配、业务新增或共享扩展及其理由。
4. **输入是什么：** 已确认需求、数据/接口、权限、环境及适用验收。
5. **怎样开发：** 已采用方法、模板/脚本或公开SDK，业务逻辑归属。
6. **输出是什么：** 内容、格式、身份、依赖、错误与受支持能力，不按阶段机械增加文件。
7. **怎样装配：** 注册/关联的Agent与运行消费者，配置和资源归属。
8. **怎样验证：** 格式/引用、接入、运行与业务效果分别采用的实际入口和独立期望。
9. **怎样修改：** 保留原资产、分析消费者影响、更新依赖、重验及必要回退。
10. **怎样交付和停止：** 入口、状态、证据、未完成/阻断、用户接受、停用与退出。

## 新建Agent

先确认目标尚不存在，按真实任务生成/复用所需组成。scaffold只提供骨架，命令与可用参数以[CLI源码](../../foundation/cli.py)及其帮助为准；执行后仍须填入真实任务内容、正确资料引用、必要工具/服务和独立案例。模板中的TODO不算完成。模板的可选目录不等于自动加载能力。

配置只使用当前消费者支持的字段。需要但未支持的业务Skill、连接器、模型能力等先列缺口与方案；不通过写一个新键名宣称接通。工具边界与业务层职责见[架构与修改](架构与修改.md)，运行时原始资料见[主索引的原生资产区](../../CODEX_START_HERE.md#原生资产与专用入口)。

## 修改与恢复

修改前读最新配置、指令、工具、服务、资料和案例，识别消费者及未提交工作。按已获准范围局部更新，保留无关内容；对已有目标不重新scaffold，不以删除重建绕过拒绝覆盖。

遇中断先核对原任务、失败位置、实际半成品及其归属，判断哪些可复用、哪些缺失，再增量补齐。记录不成功和待核实项，不自行把pending改成批准。检查结果未知的外部写入先核实副作用，不盲目重试；不建设未经批准的恢复引擎。

## 验证与交付

沿获准公共边界逐行为完成red→最小实现→同一检查green；原有不变路径复用相应回归。当前构建任务采用[第1步完整验收](第1步验收.md)；业务任务使用其自己的独立预期，不能拿模型答案生成期望。

静态配置、实际工具执行、模型回答、页面表现、评分及用户接受分别取证；具体层次与诊断方法由[验证与安全](验证与安全.md)维护。真实浏览器或助手续接要求不能由函数单测替代。行为交付按原门槛固定候选，完成独立Standards/Spec审阅，再请求用户接受。

交付用中文说明真实改变、复用/新增、数据变化、失败行为、实际结果与限制，链接同一任务记录及证据。状态更新只改其所属章节，按[文档维护](文档维护.md)同步受影响正文和索引。

## 本机开发方法与未来宿主

当前工程方法依赖宿主已安装的`coding-workflow` Skill。执行开发任务前，从宿主提供的Skill目录定位并读取其`SKILL.md`；具体测试设计读取同一Skill的`references/implementation.md`。这些宿主资源未随本仓库提供，缺失时报告方法依赖不可用，再按适用门槛处理受影响步骤。这不是已完成的Claude运行适配。

未来宿主应从同一项目读取需求、任务、配方、产物与证据，核对实际文件、版本、环境及权限后继续，并更新同一记录。宿主薄入口只映射加载和工具调用，不维护第二套流程。字段/目录/适配实现待相应任务设计；旧build.yaml示意和双worktree细案不作为当前操作命令。
