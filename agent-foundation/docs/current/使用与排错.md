# 使用入口与排错

用途：实际检查配置、查看目录页、确认操作前提和定位失败。本文拥有操作顺序与容易误判的边界；命令全集和参数查CLI帮助，具体能力/执行状态由[当前工作](当前工作.md)维护。

## 工作目录与环境

应用命令在本项目根目录执行，不在`docs/current/`文档目录中执行。

复用已有catalog环境；依赖和平台声明查[pyproject.toml](../../pyproject.toml)及实际锁文件，不在本文手抄版本。历史已验环境不证明任意平台兼容；缺环境或依赖时先说明需要验证什么、用户会看到什么及适用授权，不自动重建或安装。

## 检查与页面的操作顺序

1. 在应用根目录运行 `.venv-catalog/bin/python -B -m foundation.cli --help` 查实际命令。要核对某个Agent的配置与静态工具引用，运行 `.venv-catalog/bin/python -B -m foundation.cli inspect <agent_name>`。
2. 阅读逐项报告，不只看退出码。当前报告的结果与未验证项见[当前工作](当前工作.md#当前可核实的实现与缺口)；实现定义直接查[catalog源码](../../foundation/catalog.py)。
3. 获准查看页面且端口空闲时，启动 `.venv-catalog/bin/python -B -m foundation.web --port 7863`，打开本机对应地址。已有端口由他人进程占用时不结束它；先确认资源归属。
4. 选择Agent；新建或修改后点击“重新载入列表与配置”，再选择同一目标，和同份产物的CLI报告核对配置、模型声明及source_version。source_version只用于报告所覆盖文件的身份比较，不能代替模型、资料或环境正确性。
5. 结束本次自有服务用原终端Ctrl-C，并确认自有进程/监听已停止。历史日志中的“曾启动”不代表现在仍在运行。

这组命令的价值是环境、目录、操作顺序、重载核对与停止方法；它不镜像CLI全部参数。重复目录页验证时可按需读取原生[verify-agent-catalog配方](../../.agents/skills/verify-agent-catalog/SKILL.md)及其[场景驱动](../../.agents/skills/verify-agent-catalog/features/catalog.md)，这是专用操作消费者，保持原文件，不复制一份步骤。

## 创建或修改的入口

业务开发先按[开发方法](开发方法.md)和对应任务授权推进；新目标生成只提供骨架，还须真实内容与检查。已有目标走增量修改。共享底座变更的影响分析见[架构与修改](架构与修改.md)。

模型run/chat/eval是实际模型操作；offline demo是确定性业务示例，二者证明的事情不同。具体命令以CLI为准，当前是否允许运行以任务记录为准。不要为跟随旧快速开始而自动下载模型、启动服务或换云API。

## 按症状排错

| 症状 | 先核对什么 | 如何判断与继续 |
|---|---|---|
| Python模块缺失 | 当前解释器、实际依赖声明、错误发生在哪层 | 区分只读配置检查、业务函数和真实Runtime依赖；环境错误不是业务TDD的red，按获准范围处理 |
| 模型连接失败/模型不存在 | 实际Provider配置、服务地址、模型构件与资源权限 | 不从模板名推断已下载；不自动pull、加时或换模。模型专项暂停时只记录依赖阻断 |
| 工具引用失败 | 实际agent.yaml、tools.py符号、注册与导入路径 | 用inspect看静态问题，再分别验证Schema、导入和执行；查[修改路线](架构与修改.md) |
| 只有回答文字/没有工具结果 | 提出的调用、实际执行、返回和最终引用分别有无证据 | 可能是任务、描述、模型或Runtime问题；不由回答好看来判断工具执行 |
| 审批没有触发 | 模型是否提出被标记的操作、注册策略、真实SDK接口和执行分支 | 没有提出操作与门控失效不同；不能靠Prompt保证，也不能绕过审批修“成功” |
| CSV内容不符合预期 | 实际数据文件、来源/日期与确定性业务读取 | 样例日期会过期；任何seed/force覆盖先确认是本次可处理的合成输入，不覆盖客户数据 |
| eval失败或得分异常 | 独立预期、工具选择/参数/执行、最终答案及评分器 | 按[验证与安全](验证与安全.md)分层诊断，不直接给模型定性 |
| 页面显示旧内容或旧目标 | 同一产物路径、重载、选择和CLI报告身份 | 删除本次自有临时目标后检查旧选择是否清除；不删用户已有Agent来清场 |

真实SaaS接入由业务服务封装凭据引用、超时、限流、幂等、权限及响应校验，再暴露受限工具参数；任意URL、密钥、SQL和文件路径不直接交给模型自由决定。生产与客户数据接入另行确认，本文不是安装/运行许可。
