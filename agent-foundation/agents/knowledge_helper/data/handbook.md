# Customer Support Handbook (synthetic example)

## Severity
P0: Complete service outage with no workaround. Escalate immediately to the incident commander.
P1: Severe degradation affecting multiple customers. Escalate to on-call engineering.
P2: Limited impact with workaround available. Triage in the usual queue.

## Response process
Record the ticket ID and the customer-visible impact. Confirm reproducible steps. Avoid promising a fix date before engineering validation.

## Privacy
Do not paste customer passwords, API keys or private customer data into a support ticket. Restrict access by role.

## Escalation
A manager should be informed for P0 incidents, data-exposure risks, or repeated P1 incidents. All escalations require a link to supporting evidence.
